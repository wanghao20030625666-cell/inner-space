# 隐序 · 私人空间

一个供个人使用的记录与资料工作台。笔记、待办、项目、日历、网页和附件放在同一个可检索的空间，内容按登录账户独立保存。当前版本为 0.2.0；更新延续原有品牌，调整了布局与文案，并补齐整理内容的日常流程。

## 已实现的功能

| 区域 | 功能 |
| --- | --- |
| 主页 | 随手记、实际内容统计、置顶内容、最近编辑、待办、近期日程、小日历与专题入口 |
| 收集箱 | 快速记录，保留原记录及历史地整理成笔记、日记、待办或网页收藏 |
| 专题 | 创建、改名、标记颜色；跨模块归入同一专题；移除专题保留全部内容 |
| 笔记与日记 | 正文编辑、Markdown 分栏预览、字数、日记日期流、历史版本查看与载入 |
| 待办与项目 | 三列看板、拖放与按钮流转、优先级、截止日期、项目内新增及完成待办、按关联待办计算项目进度 |
| 日历 | 月视图、切换月份、当日日程、日期、时间、地点 |
| 网页收藏 | HTTP/HTTPS 链接、域名、备注、标签、待读/已读和原网页跳转 |
| 文件与相册 | 多文件依次上传、单文件 25 MB 限制、受保护下载、图片预览 |
| 个人账本 | 人民币收入与支出、分类、日期、当前加载列表金额汇总 |
| 联系人 | 姓名、电话、邮箱、公司或关系、备注 |
| 公共能力 | 服务端搜索与标签/状态/专题/月度筛选、星标、置顶、卡片/列表视图、批量星标/归档/移入专题/回收站、恢复与彻底删除 |
| 空间设置 | 名称、主页备注、浅色/深色主题、日历起始日、记录及专题导出、兼容 v1/v2 的文字导入 |
| 维护能力 | 内容操作日志、乐观锁、更新前版本快照、附件删除重试队列 |

当前没有邮件/短信提醒、后台定时任务、端到端加密、自动灾备或企业合规认证。

## 技术与环境

- Node.js 22.13 以上（开发验证使用 Node.js 24）。
- React 19 + TypeScript + Vinext/Vite。
- Cloudflare Workers 执行服务端代码；D1 保存结构化数据，R2 保存附件。
- Sites 平台负责站点入口访问范围与 ChatGPT 登录。应用 API 额外检查每条记录的账户归属；发布更新保留平台当前访问设置。
- Git、npm 和 Windows 自带 `tar.exe` 支持打包流程。

`.openai/hosting.json` 记录此网站的站点身份和 `DB` / `BUCKET` 绑定；复用现有 `project_id`，不要再次创建站点。

## 安装、构建与本地运行

在本项目目录执行：

```powershell
npm run install:ci
npm run db:generate
npm run build
```

首次准备本地数据库时，按顺序执行已生成的迁移。已有 0.1.0 本地库只需执行 0001。已执行的迁移不要重复运行；之后的修改应添加新迁移。

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_far_stryfe.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_nebulous_madrox.sql
npm run dev -- --port 5181 --hostname 127.0.0.1
```

打开终端给出的本地地址。开发预览通过 starter 的回环地址模拟登录，显示 `Seedy`，与线上账户及线上数据库隔离。这个模拟登录只用于本地开发，构建产物不包含此登录实现。开发服务只绑定 `127.0.0.1`，不要通过反向代理公开开发预览。

构建后的本地 Worker 可使用 `npm start` 运行，但它不模拟登录；普通使用和界面检查建议使用上述开发命令。

## 使用说明

1. 主页可直接随手记到收集箱，`Ctrl/Cmd + Enter` 保存；“新建”选择模块。编辑收集箱记录时可通过“整理为”转换内容类型。
2. 搜索框跨模块搜索标题、正文与标签；`Ctrl/Cmd + K` 聚焦搜索。
3. 每次保存内容都会生成一个版本；重新打开内容可查看最近 30 个历史版本，载入旧版后需再次保存才生效。
4. “移入回收站”保留内容和附件；可恢复。彻底删除需要额外确认，并删除该记录的版本历史及附件。
5. 文件和照片最多每个 25 MB。相册支持经文件头校验的 JPG、PNG、GIF 和 WebP；其他文件通过文件库下载。
6. 设置中的 v2 JSON 导出包含所有当前记录、回收站记录、专题、设置和附件索引。它不包含附件二进制文件、历史版本或操作日志，不能当作完整灾备镜像。附件原文件在文件库和相册单独下载。
7. 导入兼容 v1/v2，一次最多 1,000 条、文件最多 10 MB；先校验文字记录，再追加创建，跳过文件/照片及回收站记录。v2 重建专题并重新映射项目与待办的 ID；缺失项目关联留空。重复导入会产生副本；遇到错误会停止并报告已完成数量。设置不会被导入覆盖。
8. 列表每页 200 条，支持加载更多。搜索、标签、状态、阅读状态、专题及月份筛选都在服务器处理；账本金额汇总针对当前已加载列表。看板列数也对应当前已加载的待办。
9. 专题最多 100 个。移除专题会解除内容关联并更新记录版本，保留正文与附件。批量操作一次最多选择 100 条，逐条检查版本；部分失败会显示数量，不会把失败当作全部成功。
10. 项目内新增和勾选待办立即保存。有关联待办时，项目卡片的进度按有效待办完成数量计算；没有关联待办时使用手动进度。归档或回收站待办不参与进度。

## 私密访问与维护边界

站点入口的公开或私密范围由 Sites 设置。2026-11-04 更新前核对的平台状态为公开，本次沿用该设置；页面和内容 API 仍要求登录，每个 API 检查用户 ID 和记录所有权。其他登录账户不会因此读到你的记录。附件没有公开的 R2 链接，下载经过相同的身份及归属检查。需要限制站点入口时，应在平台访问设置中另行修改；不要用文案代替权限设置。

私密访问控制不等同于端到端加密；服务端需要处理明文以完成搜索、编辑和导出。此版没有自建密码认证、支付、外部 AI 调用或第三方分析脚本。

所有真实记录使用 D1/R2 持久化。浏览器不使用 localStorage 保存业务记录。`.wrangler/`、`.env*`、本地测试资料和 `outputs/` 已忽略，不能提交到源代码仓库。线上数据不会由本地迁移和测试创建或覆盖。

## 验证

先运行本地开发服务，再执行：

```powershell
node node_modules/typescript/bin/tsc --noEmit
node scripts/test-api.mjs
node scripts/test-features.mjs
python scripts/test-boundaries.py
npm run build
```

测试脚本仅允许本机开发环境，创建自己的合成数据并在结束时清理。边界脚本需要 Python 3，并读取当前项目本地 D1 数据库以建立第二个用户和分页样本；不要指向其他工作区或在线数据库。具体检查见 `docs/VALIDATION.md`。

## 常见问题

**页面显示 Seedy？** 这是本地预览身份，线上通过平台登录后会显示你的实际账户信息。

**提示记录在其他窗口更新？** 说明此窗口拿到的是旧版本。保留尚未保存的文字，刷新并查看最新内容后重新修改。接口返回 409，不会覆盖另一窗口的新内容。

**记录删除后提示附件待清理？** 元数据已删除，待删除对象键保存在持久化队列。打开“空间设置 → 附件删除重试”，直到队列清空。

**筛选后结果比当前页更多？** 筛选和数量统计由服务端处理全部匹配记录，列表每次读取 200 条。点击“加载更多”继续读取。

**更改了数据表？** 修改 `db/schema.ts`，运行 `npm run db:generate`，检查新 SQL，再分别应用本地迁移和走正常线上发布。已经应用的迁移及其元数据保持不变。

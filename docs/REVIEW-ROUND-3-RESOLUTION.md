## B 类增强

- B1：Ctrl/⌘+K 和独立命令按钮；跨模块记录搜索、模块/专题导航、新建动作；方向键/Enter、初始输入焦点、滚动定位、搜索取消。手机入口可点，390 像素无横向溢出。没有新增命令库依赖。
- B2：专题 JSON/附件 ZIP。包含该专题全部状态及关联附件；历史、操作日志限定相同范围，不带其他专题或账户偏好。沿用 SHA-256、大小、ZIP 解压和追加恢复规则。浏览器已实际下载专题 ZIP；自动测试覆盖独立附件和其他账户排除。
- B3：默认关闭的 30/90 天保留期，开启需明确勾选永久删除提示；正常内容写入后惰性清理，不加 Cron，不在设置保存或读请求上立即删除。复用手动删除事务和 blob_cleanup；owner、版本、截止时间、偏好值条件同时保护。每次最多 20 条，恢复先于清理。测试只针对自己的合成样本，检测到无关到期回收站内容会拒绝执行该清理用例。
- B4：CI 加 npm audit --audit-level=high，并修复实际扫描出的高危/严重依赖通告。没有移除审计或放宽严重级别。
- B5：附件队列报告运行状态；关闭确认明确提示未完成上传会取消，成功附件保留。正式保存若仍在上传则提示等待或先取消。
- B6：触屏/窄屏看板提供“开始/完成/重开”操作说明。

## C 类决策与证据边界

认证：Sites 身份规范采用平台注入的用户头；保留其集成和账户隔离。应用新增对直接 workers.dev URL/Host 的 403 拒绝，构建配置声明 workers_dev=false、preview_urls=false。测试覆盖子域名、端口、尾点和合法 Sites/本地地址。可用原生 Sites 工具不提供所有底层入口开关或头清洗策略的证明，因此该平台信任前提仍需保留，不能标为“已完成独立安全认证”。没有改站点受众、凭据或登录系统。

搜索：决定保持当前 instr 子串搜索，不执行 FTS 迁移。现有容量上限是每账户 10,000 条。新增 scripts/benchmark-search.mjs 用独立内存 SQLite 构造 10,000 条千字正文（当前账户 8,000 条），测同一筛选/排序/200+1 页查询：单字“读”中位 9.17 ms，“项目”19.80 ms，“账本核对”27.18 ms，“special”19.78 ms，“不存在”29.80 ms。此数据只反映本机合成基线，不代表 D1 网络或生产性能，也不能证明 FTS 的提速比例。需要真实 D1 慢查询证据、中文一/二字搜索兼容性和回滚设计后再迁移。

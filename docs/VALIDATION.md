# 0.2.0 验证记录

验证日期：2026-11-04（Asia/Shanghai）。以下是当前代码的本地验证，线上发布状态另以 Sites 发布结果为准。

## 自动检查

- TypeScript 严格类型检查通过。
- Vinext 的服务器、客户端与 SSR 构建通过。
- `scripts/test-api.mjs` 的 66 项 HTTP 断言通过，覆盖 11 类内容：匿名 API 拒绝、跨来源写入拒绝、输入校验、各模块创建读取、收藏、归档、软删除、恢复、乐观锁冲突、版本历史、文件上传下载、图片签名校验、设置保存与操作日志。
- `scripts/test-features.mjs` 的 42 项 HTTP 断言通过：专题创建/改名/移除、记录归入专题、置顶与最近编辑、收集箱转换及历史保留、阅读状态、项目待办及进度、看板状态、月份筛选、移除专题后的旧版本冲突，以及项目删除后待办仍可编辑。
- `scripts/test-boundaries.py` 通过：第二用户记录不可检索、不可修改、不可删除、不可读取历史或附件；专题不可跨账户修改、删除或关联，项目不可跨账户关联；205 条同时间戳记录（201 条置顶）跨两页不重不漏；服务端标签筛选能命中首屏之外的记录；无效日历日期被拒绝。
- 所有集成测试业务样本仅位于本地 D1/R2，脚本完成后清理。

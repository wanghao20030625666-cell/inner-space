# 0.6.2 修复与回归

日期：2026-11-05。对应上一轮功能验收确认的问题。

| 问题                  | 本版结果                                                                                                |
| --------------------- | ------------------------------------------------------------------------------------------------------- |
| 日历筛选脱节          | 标签贯穿月历、当日议程与 ICS 导出；加载失败禁用导出。                                                   |
| 项目列表只显示 200 项 | 增加游标加载更多、错误重试，刷新和从详情返回时保留已加载范围。                                          |
| 项目待办不能打开详情  | 点击名称进入完整待办编辑器，保存/关闭后返回项目，原项目未保存正文不丢失，进度重新加载。                 |
| 未保存设置离开丢失    | 表单状态在当前工作区会话保留；提供未保存说明、显式放弃与浏览器刷新/关闭提醒；危险偏好仍需手动保存确认。 |
| 操作记录说明过时      | 改为“搜索和查看内容操作记录”。                                                                          |
| 全局搜索范围不清      | 可访问名称明确普通视图跨模块、归档和回收站限各自范围。                                                  |

验证：126 项单元测试，292 项接口断言；类型、Lint、格式与构建状态按最终发布结果记录。新增单元检查项目首屏边界、下一页、返回范围、重叠去重、循环游标、部分失败和参数编码。浏览器重走空/匹配日历标签、实际 ICS 下载（空筛选 VEVENT=0）、项目 200→206 项、任务详情修改保存后返回、父正文保持、设置跨板块保留与放弃、手机宽度及控制台错误。

测试仅使用本地合成数据。没有新增依赖、迁移、后台任务或访问范围变更。修复后扩展方向见 NEXT-FEATURES.md；该文件是候选评估，不代表已经实现。
